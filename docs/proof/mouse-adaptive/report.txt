Adaptive mouse profiles, live proof, 2026-10-27, gala at 150% (dpi 144)

How the active mouse is chosen
- Windows Raw Input (RIDEV_INPUTSINK on a message-only window) reports which device sent each mouse event.
- A mouse that moves in a real burst (8 events in 400 ms) becomes the active one. Injected input (no device) is ignored.
- Before anything moves, the first known mouse model is active.
- "Switch by itself" (Settings > Your mouse) is on by default; picking a mouse by hand pins it and turns that off.
- Each mouse keeps its own speed and buttons in %LOCALAPPDATA%\Omniwand\mouse-profiles.json, keyed by VID&PID.
- No mouse lets Omniwand set real DPI (that lives in G HUB, Options+ or Synapse), so every mouse gets
  Mouse speed (Windows pointer speed 1 to 20), and Holodex says "DPI is set in your mouse's own app".

Device list
- Windows lists 5 mouse-type devices. Two Razer ones are a Huntsman V2 keyboard and a Tartarus V2 keypad (their HID
  product strings say so); they stay out of the menu unless they actually move the pointer.
- A maker-only match (no exact PID in the table) now uses the device's own product string instead of a guessed model.
