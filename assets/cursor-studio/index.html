Input Studio

Generate

The agent sees the selected cursor and returns editable shape parameters rather than a replacement picture. Image tracing stays exact; the agent interprets what is already on the canvas and changes geometry only when you ask.

Canvas

The dashed box in the editor is the cursor boundary. Anything outside it is lost when the file is written, so if a shape needs more room, raise the size rather than pushing past the edge.

Shape

Look

The rim is what keeps a dark cursor visible on a dark desktop. Drop it to zero and the shape will disappear against your own themes.

Morph

Windows restarts an animated cursor from frame zero whenever that cursor becomes current, so each morph plays once on arrival and then holds on its last frame.

Transitions

Windows role From To File

Nothing tells a cursor what the previous cursor was, so each one morphs from a shape you pick. Ring into arrow makes leaving a link reciprocal with entering it.
