# My App

Keep track of what matters.

A 4GE mobile starter: Expo (SDK 58) and React Native, adapted from Expo's official
`expo-template-blank-typescript`. Runs on iOS, Android and the web.

- `pnpm install` (or `npm install`)
- `pnpm start` opens Expo; scan the QR code with Expo Go, or press `a`, `i` or `w`
- `pnpm build` type-checks and exports the web build to `dist/`

Native store builds use EAS (`npx eas build`), which needs your own Expo account.
